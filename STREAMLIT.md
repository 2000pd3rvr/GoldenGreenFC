# Deploying Golden Green SC on Streamlit Community Cloud

1. Open [share.streamlit.io](https://share.streamlit.io/) and sign in with GitHub (`2000pd3rvr`).
2. Create app → repository `2000pd3rvr/GoldenGreenFC` → branch `main` → main file `streamlit_app.py`.
3. Choose a subdomain such as `golden-green-sc`, then deploy.

Live club site: https://huggingface.co/spaces/0001AMA/GoldenGreenFC
